# 숭실대학교 분실물센터 모바일 웹앱 (Soongsil Lost & Found)

숭실대학교 재학생 및 교직원을 위한 교내 분실물 조회 및 찾기 모바일 웹앱입니다.  
기존 인스타그램 피드(`@soongsil_lostnfound`)의 피드를 일일이 내려서 찾아야 했던 불편함을 해소하고, **카테고리별 필터링**, **관리번호/물품명 실시간 검색**, **AI 이미지 분석 및 배경 누끼 제거**, **키워드 사전 알림 서비스**를 제공합니다.

---

## 🌟 주요 기능

### 1. 인스타그램 피드형 분실물 목록 (메인 화면)
- **깔끔한 스튜디오 누끼(흰색 배경) 스타일 3열 그리드 카드 UI**
- 카드 하단에 **[카테고리 배지]**와 **[관리번호 (예: 2026-143)]** 명확히 노출
- 카테고리 필터 탭: **전체, 전자기기, 생활용품, 문구류, 귀중품, 기타** (실시간 카운트 뱃지 포함)
- 연도별(2026/2025), 단과대/건물별, 보관 상태별(보관중/수령완료) 상세 필터
- 실시간 통합 검색: 관리번호(예: `2026-162`) 또는 키워드(`삼성 노트북`, `손목시계`, `바라클라바`, `에어팟`)
- 상단 분실물센터 운영시간 및 위치 요약 배너

### 2. 물품 상세 모달 & 숭실대 공식 수령 안내
- 고해상도 확대 사진, 관리번호, 카테고리, 등록일, 보관 상태(보관중/수령완료), 상세 습득 위치 및 특징 태그 표시
- **'내 물건 찾기 (수령 방법 안내)'** 원클릭 안내 팝업:
  - **센터 위치:** 숭실대학교 학생회관 406호 (학생서비스팀)
  - **운영 시간:** 학기 중 09:00 ~ 17:30 / 방학 중 10:00 ~ 17:00 (점심시간 12:00 ~ 13:00)
  - **문의 전화:** `02-820-0164` (원클릭 전화 걸기 링크)
  - **수령 절차:** 관리번호 확인/복사 → 학생회관 406호 방문 → 본인 소유 증빙(잠금화면 비밀번호, 외관 특징 확인 등)
  - **보관 기간:** 등록일로부터 1년 보관 (상할 수 있는 음식물은 다음 날 즉시 폐기)
  - **관리번호 원클릭 클립보드 복사 기능**

### 3. 습득물 제보 및 AI 자동 분류 (학생 참여 & 관리자)
- 물품 사진 업로드/촬영 시 **AI 자동 누끼(Canvas 배경 제거) 처리**로 인스타 규격 흰색 배경 변환
- 이미지 특징 및 키워드 기반 **AI 카테고리 & 태그 자동 추천** (정확도 점수 표시)
- 숭실대학교 주요 건물 드롭다운(정보과학관, 형남공학관, 중앙도서관, 학생회관 등) 선택

### 4. 내 분실물 키워드 알림 등록
- 찾는 물건이 아직 등록되지 않았을 때 원하는 키워드(예: `바라클라바`, `손목시계`)와 카테고리를 등록
- 일치하는 분실물이 등록되거나 기존 목록에서 발견되면 **실시간 인앱 알림(종 모양 아이콘 배지)** 수신
- '피드 바로보기' 버튼을 통해 일치 물품으로 원클릭 이동
